۱. جدول انواع معادلات شاخص (مشخصه) در جداسازی متغیرها

هنگام حل معادله مکانی $X'' - \sigma X = 0$، معادله شاخص $r^2 - \sigma = 0 \implies r^2 = \sigma$ تشکیل می‌شود که بر اساس علامت ثابت جداسازی $\sigma$ سه حالت دارد:

حالت ثابت جداسازی ($\sigma$) ریشه‌های معادله شاخص ($r^2=\sigma$) جواب‌های پایه ($y_1, y_2$) جواب عمومی $X(x)$ و مشتق آن $X'(x)$
حالت اول: $\sigma = 0$
($\Delta = 0$)		 $r_1 = r_2 = 0$
(ریشه مضاعف)		 $y_1 = 1, \quad y_2 = x$ $X(x) = c_1 + c_2 x$
$X'(x) = c_2$
حالت دوم: $\sigma > 0$
($\sigma = \lambda^2, \lambda > 0$)		 $r_1 = +\lambda, \quad r_2 = -\lambda$
( دو ریشه حقیقی متمایز)		 $y_1 = e^{\lambda x}, \quad y_2 = e^{-\lambda x}$ $X(x) = c_1 e^{\lambda x} + c_2 e^{-\lambda x}$
$X'(x) = c_1 \lambda e^{\lambda x} - c_2 \lambda e^{-\lambda x}$
حالت سوم: $\sigma < 0$
($\sigma = -\lambda^2, \lambda > 0$)		 $r_1 = +\lambda i, \quad r_2 = -\lambda i$
(ریشه‌های مزدوج مختلط)		 $y_1 = \sin(\lambda x), \quad y_2 = \cos(\lambda x)$ $X(x) = c_1 \sin(\lambda x) + c_2 \cos(\lambda x)$
$X'(x) = c_1 \lambda \cos(\lambda x) - c_2 \lambda \sin(\lambda x)$

۲. جدول جامع انواع سری‌های فوریه مورد نیاز در PDE

نوع سری فوریه بازه و کاربرد مرزی فرم بسط سری فرمول محاسبه ضرایب انتگرالی
سری فوریه سینوسی
(نیم‌دامنه فرد)		 $[0, l]$
دو سر دمای صفر:
$u(0,t)=u(l,t)=0$		 $$f(x) = \sum_{n=1}^{\infty} c_n \sin\left(\frac{n\pi x}{l}\right)$$ $$c_n = \frac{2}{l} \int_{0}^{l} f(x) \sin\left(\frac{n\pi x}{l}\right) dx$$
سری فوریه کسینوسی
(نیم‌دامنه زوج)		 $[0, l]$
دو سر عایق حرارتی:
$u_x(0,t)=u_x(l,t)=0$		 $$f(x) = \frac{a_0}{2} + \sum_{n=1}^{\infty} a_n \cos\left(\frac{n\pi x}{l}\right)$$ $$a_0 = \frac{2}{l} \int_{0}^{l} f(x) \, dx$$$$a_n = \frac{2}{l} \int_{0}^{l} f(x) \cos\left(\frac{n\pi x}{l}\right) dx$$
سری فوریه کامل $[-l, l]$
شرایط مرزی تناوبی		 $$f(x) = \frac{a_0}{2} + \sum_{n=1}^{\infty} \left( a_n \cos\frac{n\pi x}{l} + b_n \sin\frac{n\pi x}{l} \right)$$ $$a_0 = \frac{1}{l} \int_{-l}^{l} f(x) dx, \quad a_n = \frac{1}{l} \int_{-l}^{l} f(x)\cos\frac{n\pi x}{l} dx$$$$b_n = \frac{1}{l} \int_{-l}^{l} f(x)\sin\frac{n\pi x}{l} dx$$

۳. اتحادهای مثلثاتی تبدیل ضرب به جمع و کاهش توان

  • $\sin(A)\sin(B) = \frac{1}{2}\big[\cos(A-B) - \cos(A+B)\big]$
  • $\cos(A)\cos(B) = \frac{1}{2}\big[\cos(A-B) + \cos(A+B)\big]$
  • $\sin(A)\cos(B) = \frac{1}{2}\big[\sin(A+B) + \sin(A-B)\big]$
  • $\sin^2(\theta) = \frac{1-\cos(2\theta)}{2} \quad , \quad \cos^2(\theta) = \frac{1+\cos(2\theta)}{2}$

۴. مقادیر مرزی، انتگرال‌های جزبه‌جز و روابط هذلولوی

  • $\sin(n\pi) = 0 \quad , \quad \cos(n\pi) = (-1)^n \quad , \quad 1-(-1)^n = \begin{cases} 0 & n \text{ زوج} \\ 2 & n \text{ فرد} \end{cases}$
  • $e^{\lambda l} - e^{-\lambda l} = 2\sinh(\lambda l) \quad (\sinh(x)=0 \iff x=0)$
  • $\int x \sin(ax) dx = -\frac{x}{a}\cos(ax) + \frac{1}{a^2}\sin(ax)$
  • $\int x \cos(ax) dx = \frac{x}{a}\sin(ax) + \frac{1}{a^2}\cos(ax)$
